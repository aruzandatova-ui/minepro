# Minesweeper Game

간단한 Pygame 기반 지뢰찾기 게임입니다. 플레이어는 지뢰를 피해서 모든 안전한 칸을 열어야 합니다.

---

## 기능

1. **숫자 색상 표시** (#8)  
   각 칸에 표시되는 숫자별로 색상이 다르게 표시됩니다.

2. **난이도 설정** (#9)  
   Easy, Medium, Hard 난이도에 따라 보드 크기와 지뢰 수가 달라집니다.

3. **힌트 기능** (#10)  
   지뢰가 없는 칸을 한 칸 확인할 수 있습니다.(H)

4. **하이 스코어 표시** (#11)  
   게임 종료 시 최고 점수를 표시합니다.

5. **타이머 표시** (#12)  
   게임 진행 시간을 화면에 표시합니다.

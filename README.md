# Minesweeper Game

간단한 Pygame 기반 지뢰찾기 게임입니다. 플레이어는 지뢰를 피해서 모든 안전한 칸을 열어야 합니다.

---

## 기능

1. **숫자 색상 표시** (#2)  
   각 칸에 표시되는 숫자별로 색상이 다르게 표시됩니다.

2. **게임 타이머** (#3)  
   게임 시작 후 경과 시간을 화면에 표시합니다.

3. **재시작 버튼** (#4)  
   게임 화면 상단에 "Restart" 버튼을 눌러 게임을 재시작할 수 있습니다.

4. **깃발 카운터 표시** (#5)  
   남은 깃발 수를 화면에 표시합니다.

5. **깃발 배치 사운드 효과** (#6)  
   깃발을 배치할 때 효과음이 재생됩니다.
